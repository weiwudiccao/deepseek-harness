# Agent Note: 企福隔离浏览器检查

Status: implemented

[English](2026-11-05-qifu-isolated-browser-checks.md) | 中文

## 问题

为 Agent 检查启动个人浏览器，会让页面检查依赖员工登录态和加密浏览器存储。在命令执行器的文件沙箱内初始化原生渲染器沙箱时，独立 Chrome 进程也可能失败。替换 HOME 或关闭沙箱不能保留预期隔离；单靠模型指令，也不能保证特定启动方式或等待清理完成。

## 决定

独立启用的企福 `browser_test` 工具只接受不含内嵌凭据的 HTTP(S) URL。它通过桌面应用已有的 Electron 引擎读取 DOM，使用全新的沙箱渲染器，关闭 Node 集成、启用上下文隔离并使用内存分区。桌面端点拒绝权限请求、下载和非 HTTP(S) 导航。该流程不涉及个人浏览器配置、钥匙串设置、独立 Chrome 安装或子进程启动。

桌面启动器向其本机 Harness 运行时提供随机 bearer token 和固定路径的回环 URL。Host 直接使用 HTTP，不经过环境代理，也不跟随重定向，不把端点或凭据作为模型参数。UUID 和创建时间请求头在请求正文完整到达前标识请求；取消使用相同身份。DOM 输入和输出在传输解析器处限制大小并校验。成功结果只包含请求的规范化 URL、DOM 和截断标志，全部通过工具结果记录。

超时、取消或卸载时，等待桌面端点确认渲染器销毁。未知取消身份在其 POST 随后到达时仍保持已取消；确认失败仍然报错。桌面端点负责渲染器生命周期，强制执行 30 秒截止时间、1 MiB DOM 上限和两个并发读取。Host 配置可以缩小截止时间和输出上限。这是沙箱浏览器读取，不声称会话的 DSH 文件系统策略约束该渲染器。

浏览器指引要求模型使用该工具。独立的工具拦截器拒绝静态可识别的 Bash 直接 Chrome、Chromium 或 Edge 启动；PowerShell 仅识别首个字面量浏览器可执行文件，可带 `&` 调用符和一次位于前面的字面量 `$env:HOME` 赋值。该拦截器不是任一 shell 的完整解析器，不解析别名、间接脚本、动态求值、后续 PowerShell 命令或其他启动机制。[企福桌面宿主操作决策](../architecture/2026-10-30-qifu-desktop-host-operations.zh.md) 继续负责员工运行时世代、网关凭据和原生对话框。

## 考虑过的替代方案

**只使用模型指令。** 指引不能确立隔离渲染器设置或等待销毁；桌面端点负责这些性质。对于拦截器无法识别的启动路径，指引仍然有用。

**启动独立 Chrome 或替换 HOME。** 第二个浏览器重复已有桌面引擎的能力，并要求按平台管理配置、崩溃报告、临时文件和嵌套沙箱。替换 HOME 改变文件系统身份，不能证明个人浏览器状态不存在。

**关闭浏览器或主机沙箱。** 启动失败不能变成不受限重试。渲染器保留原生沙箱；工具不执行需要扩大 DSH 文件权限的 shell 命令。

## 影响

该工具提供 DOM 证据，不提供截图、视觉排版保真、交互自动化或员工已有浏览器登录态。HTTP(S) 导航没有目标主机白名单，不提供网络隔离。必须具备已鉴权的桌面桥；独立 CLI 在缺失该服务时不会静默启动另一浏览器。

回环 HTTP 测试覆盖端点和 token 校验、URL 拒绝、有界多字节 DOM、损坏响应、传输失败、取消确认、超时、卸载和清理失败。它们不能证明原生渲染器设置，或真实安装环境一定没有操作系统提示；该证据由发布验收负责。
